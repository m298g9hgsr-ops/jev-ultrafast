# VS Code 最基本配置

- .vscode/extensions.json：工作區推薦擴充
- .vscode/settings.json：基本格式化與自動儲存

## 用法
1. 把 .vscode/ 資料夾複製到專案根目錄（或直接把這兩個檔案放進 .vscode/ 裡）
2. 開啟 VS Code，右下角會跳出「建議安裝擴充套件」，點「安裝全部」就好
3. 儲存檔案時就會自動格式化
